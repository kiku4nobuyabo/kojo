# 信長の野望・真戦 攻城シミュレータ v0.1

## 起動方法

1. ZIPを展開する。
2. `index.html` をダブルクリックしてブラウザで開く。
3. 城数（1〜3）、手持ち兵器部隊数、兵器攻城値、共通体力、各城の耐久度と割当数を入力する。

GitHub Pagesなどに4ファイル（`index.html`、`style.css`、`app.js`、`calculator.js`）をそのまま公開しても動きます。通信、DB、外部API、アカウントは不要です。`tests/` は公開しなくても構いません。

## 主な機能

- Lv4 / Lv5 / Lv6 / Lv7の城耐久度をプリセット選択。関所・Lv8等は耐久値を手動入力。
- 1〜3城の同時攻城、使える兵器総数との突合、手持ちと最低必要数を比較。
- 全兵器共通の体力を0〜100の10刻みで選択。体力10につき1回、最大10回。
- 1回5分の攻城を想定し、必要攻撃回数と所要時間を表示。体力が足りなければ理論値と明記。
- 各城ごとの削れる耐久と残耐久率の推移グラフ。
- 必要最低部隊数へワンクリックで自動配分（手持ち超過の場合は警告）。
- テキスト結果のコピー（ゲーム内連絡やDiscordへの貼り付け用）。
- 入力中の条件をローカル自動保存。最大20件の名前付き条件保存・読込・削除。

## 計算式

- 1回の攻城値合計 = 割当兵器数 × 1部隊攻城値
- 必要攻撃回数 = ceil(耐久値 ÷ 1回の攻城値合計)
- 最大攻撃回数 = min(10, floor(現在体力 ÷ 10))
- 所要時間 = 必要攻撃回数 × 5分
- 最低必要兵器数 = ceil(耐久値 ÷ (1部隊攻城値 × 最大攻撃回数))

部隊数が0、体力が0のケースは計算不能・不成立として扱います。

**注意**：これは駐城軍の殲滅後の「城耐久削り」に関する目安です。守備軍殲滅、進軍時間、部隊の遅延、兵損、攻撃失敗、回復等は計算しません。最大攻撃回数が10なので、通常の設定では必要攻撃回数11回（55分）以上はそもそも体力不足です。時間リスク区分は50分以下＝問題なし、55分＝ギリギリ、60分＝危険、60分超＝警告として計算ロジック上に保持しています。

## 保存について

保存先は利用中ブラウザの `localStorage` です。端末やブラウザが変わると同期されません。シークレットモードなどでは保存が維持されない場合があります。個人用設定の保存にDBは使いません。

## 検証

Node.jsを利用できる場合、フォルダ内で `node --test tests/calculator.test.cjs` を実行すると計算ロジックの自動テストができます。
